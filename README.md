# PHD115 · Chemistry with Dr. NAM

Lecture slides for PHD115 Fundamentals of Chemistry (Dr. Nur 'Ainun Mokhtar).

- `index.html`: home page listing all lectures
- `ic1/`, `em/`: interactive lecture slides (one folder per topic)
- `downloads/`: PowerPoint versions
- `js/three.min.js`: 3D library used for the molecule decorations

## Adding a new topic
Add its folder (for example `ic2/index.html`), put its PowerPoint in `downloads/`, and add a card to `index.html`.

Content adapted from *The Basics of GOB Chemistry* (Ball, Hill & Scott), LibreTexts, CC BY-NC-SA 3.0.
