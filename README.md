# PHD115 · Chemistry with Dr. NAM · Study Hub

Self-instructional materials for Dr. NAM's PHD115 topics (Faculty of Pharmacy, UiTM Bertam, Penang).

- `index.html`: the study hub (browse by topic or by activity; progress saved per device; reset)
- `<topic>/slides/`: interactive lecture slides (ic1, em, ...)
- `<topic>/pre/`, `post/`, `tutorial/`, `game/`: added as they are built
- `downloads/`: PowerPoint versions
- `js/three.min.js`: 3D library for the molecule decorations

To add an activity: upload its folder, then upload the updated `index.html` (its path is filled in the TOPICS list).

Content adapted from *The Basics of GOB Chemistry* (Ball, Hill & Scott), LibreTexts, CC BY-NC-SA 3.0.
